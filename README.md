
# PassportPulse Streamlit Dashboard

AI-powered social media scraper dashboard for passport-related posts.

## Features

- Social media dashboard
- AI summaries
- Translation support
- Sentiment analysis
- Search and filtering
- Analytics charts
- Streamlit UI

## Installation

pip install -r requirements.txt

## Run

streamlit run app.py

## Tech Stack

- Streamlit
- Python
- MongoDB
- NLP
- TextBlob
- Deep Translator
